# Front Porch Collective — Company Branding
**Standing order from Leon (2026-08-14, bible v1.3): the FPC monogram is part
of every agent's identity and ships on every product from every division.**

## The mark

Interlocking **F + P** sharing a single vertical stem, with a clay dot
terminal. Primary form: the monogram on an ink app tile. Bare monogram on
light grounds only.

## Files in this folder (SVG — scale to anything)

| File | Use |
|---|---|
| `FPC-monogram-primary.svg` | Ink mark + clay dot — light backgrounds |
| `FPC-monogram-reversed.svg` | Bone mark + clay dot — dark backgrounds |
| `FPC-monogram-onecolor.svg` | Single-color ink — embroidery, engraving, fax |
| `FPC-appicon-tile.svg` | Rounded ink tile, reversed mark — app icons, avatars, favicons |

Full raster set (1480px marks, 1024 app icon, 256/64/32 favicons) lives in the
home base at `admin/branding/handoff/png/` — ask Leon or Smokey to relay any
size you need.

## Where it goes

- **Websites:** favicon + app-tile in the header or footer (Web Division: on
  every client build where the contract allows a "built by" credit, and on
  every Front Porch–owned property always).
- **Apps:** app icon derived from the tile; splash and about screens carry the mark.
- **Scripts & documents:** title page carries the tile, stacked lockup.
- **Decks & one-pagers:** tile on the cover, monogram on interior footers.

## Color

| Name | Hex | Use |

| Ink | `#201C1A` | Primary dark — tiles, type |
| Clay | `#B45A38` | Accent ONLY — dot terminal, active states, links |
| Bone | `#F4F1EA` | Reversed mark, light type on ink |
| Sand | `#ECE3D3` | Background tint |

## Type

- **Playfair Display 600** — wordmark and headlines ("Front Porch")
- **Jost 400** — "COLLECTIVE" lockup line (0.42em letterspacing, uppercase) and all UI

## Lockups, clear space, minimums

Stacked: tile above, "Front Porch" + COLLECTIVE centered below. Horizontal:
tile left, wordmark right, gap = 1/3 tile width. Clear space all sides = 1/4
tile width. Minimum tile 20px digital / 8mm print; below 32px use the tile,
never the bare monogram.

## Don't

Do not recolor the mark outside the palette, add effects or shadows, stretch
it, rotate it, or place the bare ink monogram on a dark ground (use reversed).
Violations are accuracy defects — reviewers (Cricket, Ruby, and peers) flag
them like any other.
