# Client work

One folder per client. Each one holds the brief, the assets the client gave us,
and a record of where the build lives — not the build itself. Client sites are
built where the client will own them, which for most of these is Lovable.

Company law applies here exactly as it does to our own site: nothing about a
client is guessed (rule 11), and nothing of theirs is published, sent or shown
publicly without their permission (rule 16). A fact we were not given is a
marked blank, not a plausible sentence.
